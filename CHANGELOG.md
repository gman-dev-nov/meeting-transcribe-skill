# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

Записи этого файла — исходник текста релиза на GitHub: скилл показывает
пользователю именно буллеты из тела релиза, поэтому они пишутся для человека,
а не как пересказ коммитов.

## [Unreleased]

### Добавлено

- Двойной проход поддерживает `--whisper-language ru|auto|en` и автоматически добавляет подтверждённые личные термины к подсказке Whisper; доступны явный словарь встречи и отключение автоподсказки.
- Отдельная проверка самоисправлений во всём тексте, включая согласные участки ASR, и редакторский clean-экспорт с журналом точных правок, проверкой исходников и подтверждениями спорных фактов.
- Опциональный экспериментальный адаптер локальной GigaAM Duo из установленного Type: без постобработки, сети и чтения профиля Type; с сегментными таймкодами и явными ограничениями.
- Диагностика подозрительных повторов и нулевых длительностей ASR без удаления текста или автоматического выбора версии; comparison привязан к исходным сегментам контрольными суммами.

- Поддержка Codex в приложении и CLI: установка скилла, метаданные интерфейса и смысловая сверка активной моделью, включая Astra.
- Личный словарь постоянных замен: `hybrid.py lexicon add "как слышится" "канон"`. Если модель регулярно пишет одно и то же слово не так, как нужно вам, правило фиксируется в `~/.config/meeting-transcribe/lexicon.json` (вне каталога скилла — переживает обновления) и действует во всех следующих транскрипциях: кириллица чинится вместе со склонениями, латиница — точной формой, омонимы (`рага`, `аппы`) можно помечать без автозамены. `normalize`/`plan` подхватывают словарь автоматически, личные записи перекрывают встроенные. Команда `lexicon prompt` собирает из словаря строку «Термины: …» для `--initial-prompt`, чтобы словарь влиял и на само распознавание.

### Исправлено

- Команды скилла используют его собственный каталог и работают из другой рабочей папки; уточнены язык записи и последовательный запуск двух ASR по умолчанию.
- При отсутствии расхождений отчёт создаётся без лишнего ожидания; по запросу доступен предварительный отчёт с явными неподтверждёнными пунктами.
- Копии в хранилище плагинов Codex защищены от обновления через git, в том числе при использовании симлинков и нестандартного CODEX_HOME.
- Диаризация Resemblyzer сохраняет исходную шкалу времени: удаление пауз внутри реплики больше не сдвигает следующие реплики относительно ASR-таймкодов.
- Метки SPEAKER_XX назначаются по общей шкале спикеров и остаются одинаковыми в GigaAM и Whisper при разной сегментации текста.

## [1.0.1] — 2026-08-28

### Исправлено

- Пункт списка изменений, перенесённый в CHANGELOG на несколько строк, больше не обрывается на середине фразы в уведомлении об обновлении.
- В уведомлении называется каталог проверяемой копии скилла, а не каталог, из которого запущен скрипт.

## [1.0.0] — 2026-08-28

Первая версия с номером. Фиксирует состояние скилла на момент появления
версионирования и добавляет проверку обновлений.

### Добавлено

- Двойной проход GigaAM v3 и Whisper `large-v3` для русских записей:
  два полных независимых прохода, выравнивание по таймингам и разбор
  смысловых расхождений через активный LLM.
- Спорные места подтверждает человек: скилл показывает точный интервал
  записи и обе версии, но сам ничего не исправляет.
- Диаризация спикеров через pyannote или resemblyzer — по запросу.
- Отчёт на русском по фиксированному шаблону: TL;DR, темы, решения,
  action items, цитаты с тайм-кодами, открытые вопросы, follow-ups.
- Wizard окружения `scripts/setup_check.py`.
- Проверка обновлений после готового отчёта: скилл раз в сутки смотрит,
  не вышла ли новая версия, показывает список изменений и предлагает
  обновиться. Обновление — только по явному согласию и только если в
  каталоге скилла нет незакоммиченных правок.
- Проверка обновлений выключается целиком:
  `MEETING_TRANSCRIBE_NO_UPDATE_CHECK=1`.
