## [1.0.1] — 2026-08-28

### Исправлено

- Пункт списка изменений, перенесённый в CHANGELOG на несколько строк, больше не обрывается на середине фразы в уведомлении об обновлении.
- В уведомлении называется каталог проверяемой копии скилла, а не каталог, из которого запущен скрипт.

## [1.0.0] — 2026-08-28

Первая версия с номером. Фиксирует состояние скилла на момент появления
версионирования и добавляет проверку обновлений.

### Добавлено

- Двойной проход GigaAM v3 и Whisper `large-v3` для русских записей:
  два полных независимых прохода, выравнивание по таймингам и разбор
  смысловых расхождений через активный LLM.
- Спорные места подтверждает человек: скилл показывает точный интервал
  записи и обе версии, но сам ничего не исправляет.
- Диаризация спикеров через pyannote или resemblyzer — по запросу.
- Отчёт на русском по фиксированному шаблону: TL;DR, темы, решения,
  action items, цитаты с тайм-кодами, открытые вопросы, follow-ups.
- Wizard окружения `scripts/setup_check.py`.
- Проверка обновлений после готового отчёта: скилл раз в сутки смотрит,
  не вышла ли новая версия, показывает список изменений и предлагает
  обновиться. Обновление — только по явному согласию и только если в
  каталоге скилла нет незакоммиченных правок.
- Проверка обновлений выключается целиком:
  `MEETING_TRANSCRIBE_NO_UPDATE_CHECK=1`.
