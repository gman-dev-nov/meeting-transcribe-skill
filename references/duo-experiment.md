# Эксперимент с GigaAM Duo из Type

Отдельный добровольный эксперимент на macOS с установленным Type. Он не меняет
обычный запуск, `dual` или основной ASR. Скрипт использует внутренний native addon
приложения; это не официальный standalone SDK. Проверяется известная поставка
`type.v1.019.20260917`, модель `asr.gigaam_duo.v1.3`. Другая поставка завершается
ошибкой до запуска распознавания.

```sh
node scripts/duo_transcribe.cjs "/absolute/path/recording with spaces.wav" \
  --app /Applications/Type.app \
  --output-dir "/absolute/path/duo results" \
  --chunk-seconds 20
```

Нужны Node.js, локальные `ffmpeg` и `ffprobe` в PATH; если их нет, скрипт проверяет
`Contents/Resources/bin` приложения. Ничего не устанавливается и не скачивается.
GUI Type не запускается. Пользовательский профиль и кеш Type не читаются.
Временный `modelRoot` ссылается только на bundled ASR, passthrough и core;
две обязательные записи каталога LLM содержат только метаданные, без весов.
Постобработка выключена (`llm_off`). Модели не копируются в репозиторий и не
расшифровываются. Временный PCM удаляется после завершения, включая ошибку.
Сообщения native runtime `Deferred submodel ... model.tar` ожидаемы для пустых
записей выключенных LLM; они не означают отказ ASR, если команда завершилась успешно.

Результат — `<исходное имя с расширением>.duo.transcript.json` и `.md` в указанной
папке. JSON имеет обычные `metadata` и `segments` с `start`, `end`, `text`;
точная модель, версия приложения и release сохранены в метаданных. Существующие
результаты не перезаписываются; при ошибке ASR итог не публикуется.

Метки времени относятся **к чанкам, не к словам**. `words` не создаётся. Чанки
фиксированы (по умолчанию 20 секунд, допустимо 1–25); на границе можно потерять
или испортить слово. Это не VAD и не диаризация. Сравнивать с текущим ASR нужно
на одном аудио: отдельно проверять русский текст, английские названия и термины,
числа и отрицания, обрывы на границах. Само имя Duo не доказывает превосходство
на встречах. Редактирование оговорок и стиля здесь намеренно не включается.

Type заявляет MIT на [сайте приложения](https://gigatype.app/), но отдельного
публичного SDK и model card Duo не найдено. Эксперимент зависит от внутреннего
ABI установленного приложения и не является обещанием независимой переносимой
поставки модели. Для открытого backend есть
[GigaAM Multilingual](https://huggingface.co/ai-sage/GigaAM-Multilingual), качество
которого на смешанной русско-английской речи также нужно измерять отдельно.
